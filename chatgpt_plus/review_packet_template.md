# Mẫu gửi code để kiểm tra

Dùng để gom yêu cầu, code hiện tại và lỗi bạn muốn kiểm tra vào một tin nhắn. Không cần Git, mã task hoặc kết quả kiểm thử để bắt đầu.

## Mẫu để copy

```text
Hãy kiểm tra code sau, chỉ nhận xét và đề xuất cách sửa.
Chức năng cần có: [điền]
Code cần kiểm tra: [dán/đính kèm, ghi tên file nếu có]
Phần muốn tập trung: [tùy chọn]
Lỗi hoặc kết quả khác mong đợi: [tùy chọn]
Kết quả kiểm thử đã chạy: [tùy chọn; ghi lệnh và kết quả thật nếu có]

Chỉ nhận xét phần đọc được; nêu lỗi có căn cứ, vị trí và cách kiểm tra. Tách điểm chưa rõ khỏi lỗi đã chứng minh. Kết quả kiểm thử cũ hoặc chưa chạy không chứng minh code hiện tại đã chạy đúng.
```

## Ví dụ

Kiểm tra hàm tính tổng giỏ hàng khi số lượng là 0; gửi hàm, giá/số lượng và kết quả mong đợi. Chưa chạy kiểm thử thì ghi chưa chạy.
