## Cách dùng

1. Chọn mẫu phù hợp, copy khối có sẵn và điền các ô trong ngoặc vuông.
2. Dán hoặc đính kèm nội dung liên quan; ô tùy chọn có thể bỏ.
3. Kiểm tra kết quả, gửi phần cần sửa và thông tin mới nếu có.

Chỉ ghi đường dẫn trên máy không có nghĩa AI đọc được file. Code đề xuất chưa có nghĩa file đã được sửa hay kiểm thử đã chạy; kiểm tra trước khi áp dụng. Không gửi mật khẩu, khóa bí mật hoặc dữ liệu riêng tư không cần thiết.

Tên file được giữ để các liên kết cũ vẫn dùng được. Thư mục có 7 file hướng dẫn/prompt/mẫu; với tác vụ code thông thường cũng có thể dùng [nhóm lập trình](../lap_trinh/README.md).
