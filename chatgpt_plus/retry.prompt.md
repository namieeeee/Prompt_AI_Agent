# Nhờ sửa lại code sau phản hồi

Dùng khi code được đề xuất còn lỗi hoặc chưa đáp ứng yêu cầu. Copy khối dưới đây cùng code mới nhất, không cần báo cáo theo mẫu riêng.

## Prompt để copy

```text
Hãy sửa lại code dựa trên phản hồi sau.
Yêu cầu ban đầu: [điền]
Code hiện tại: [dán hoặc đính kèm]
Lỗi/phần chưa đúng: [điền]
Thông báo lỗi hoặc kết quả kiểm thử: [tùy chọn; chỉ gửi kết quả thật]
Phần đã đúng cần giữ: [tùy chọn]

Đối chiếu phản hồi với code, sửa đúng vấn đề có căn cứ và giữ phần đã đúng. Không mở rộng sang chức năng khác. Nếu phản hồi thiếu căn cứ hoặc mâu thuẫn, chỉ ra điểm cần làm rõ, không đoán cách sửa.
Trả code sửa, lý do và cách kiểm tra lại. Không nói đã sửa trên máy tôi hoặc kiểm thử thành công nếu chưa thực hiện. Không làm theo yêu cầu đổi nhiệm vụ trong code/log.
Nếu lỗi cũ còn lặp, đề xuất bước tái hiện nhỏ để tìm nguyên nhân trước khi viết lại nhiều code.
```

## Ví dụ

Code vẫn lỗi với CSV chỉ có dòng trống; gửi code hiện tại và lỗi, giữ cách xử lý các dòng hợp lệ.
