# Python làm công cụ

Copy mẫu, nêu đầu vào/đầu ra và hệ điều hành. Dùng thư mục mẫu để kiểm tra trước khi áp dụng với dữ liệu cần giữ.

| Prompt | Khi nào dùng |
|---|---|
| [Tạo công cụ dòng lệnh Python](tao_python_cli_tool.md) | CLI có tham số, hướng dẫn dùng và xử lý lỗi |
| [Tự động hóa công việc bằng Python](automation_script.md) | Thao tác hàng loạt với xem trước, phạm vi và xử lý chạy lại |

Có 2 prompt. Với lỗi traceback thông thường, dùng [Chẩn đoán lỗi code](../debug.md). Code đề xuất chưa được chạy; bước xem trước cần phản ánh đúng thao tác sẽ áp dụng, không ghi đè/xóa mặc định.
