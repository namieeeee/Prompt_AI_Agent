# Học và làm code cùng AI

Chọn một mẫu theo việc cần làm, copy khối prompt và thay các ô trong ngoặc vuông. Gửi code/tài liệu đọc được; đường dẫn trên máy không tự cho AI quyền đọc file.

| Prompt | Khi nào dùng |
|---|---|
| [Hiểu repository trước khi viết code](hieu_repo_truoc_khi_code.md) | Đọc dự án mới, tìm điểm bắt đầu và luồng xử lý |
| [Thêm tính năng vào dự án cùng AI](trien_khai_tinh_nang_cung_ai.md) | Tích hợp tính năng nhỏ, giữ hành vi cũ và hiểu thay đổi |
| [Hiểu code để tự sửa được](giai_thich_code_de_hoc.md) | Học từ code mẫu/AI, theo dõi dữ liệu và tự làm bài sửa nhỏ |
| [Chẩn đoán lỗi code](../debug.md) | Debug dựa trên lỗi, giả thuyết và kiểm tra nhỏ |
| [Kiểm tra code và đề xuất kiểm thử](../review_test.md) | Kiểm tra cả code AI tạo trước khi áp dụng |

Có 3 prompt mới trong thư mục; 2 liên kết cuối dùng lại prompt chung. Không cần bộ điều phối, nhiều chat hay mẫu báo cáo kỹ thuật. Code đề xuất chưa đồng nghĩa file đã sửa hoặc kiểm thử đã chạy.
