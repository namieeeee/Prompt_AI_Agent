# Embedded C/C++

Copy mẫu theo mục tiêu và gửi code/tài liệu đúng chip/board. Không mặc định STM32, Cortex-M, HAL hoặc RTOS. Datasheet của chip, reference manual và schematic của board bổ sung cho nhau.

| Prompt | Khi nào dùng |
|---|---|
| [Đọc datasheet theo việc cần làm](doc_datasheet_reference_manual.md) | Tìm clock, pin, thông số và thứ tự cấu hình có căn cứ |
| [Chẩn đoán lỗi firmware](debug_firmware_embedded.md) | Phân biệt code, cấu hình và số đo trên board |
| [Kiểm tra code C/C++ nhúng](review_embedded_c_cpp.md) | Bộ nhớ, kiểu dữ liệu, register, ISR và dữ liệu chia sẻ |

Có 3 prompt. Nếu mới học con trỏ, mảng hoặc STL, dùng [Hiểu code để tự sửa được](../ai_coding/giai_thich_code_de_hoc.md) trước. Gửi trích đoạn bài học/code đọc được; ví dụ trên máy không chứng minh firmware chạy đúng trên chip. Không chạy file thực thi chưa kiểm tra từ tài liệu tải về.
