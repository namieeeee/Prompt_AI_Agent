# Học tập và luyện tập

Chọn prompt theo việc cần làm, copy khối `Prompt để copy` và thay các ô trong ngoặc vuông. Đọc phần `Cách dùng` để biết cần cung cấp gì; ô tùy chọn có thể bỏ.

| Prompt | Tình huống minh họa |
|---|---|
| [Giải thích một khái niệm](giai_thich_khai_niem.md) | Giải thích đệ quy cho người biết vòng lặp Python nhưng chưa học cấu trúc dữ liệu. |
| [Tạo lộ trình học](lo_trinh_hoc.md) | Học SQL để viết báo cáo trong sáu tuần, bốn giờ mỗi tuần, hiện biết Excel. |
| [Luyện tập có phản hồi](luyen_tap_tuong_tac.md) | Luyện năm câu tiếng Anh A2, tập thì quá khứ, từng câu một. |

Không gửi mật khẩu, khóa bí mật hoặc dữ liệu riêng tư không cần thiết. Kiểm tra lại kết quả trước khi sử dụng.
