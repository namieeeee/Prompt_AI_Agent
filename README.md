## Cách sử dụng

1. Chọn nhóm và mở prompt phù hợp.
2. Copy khối `Prompt để copy` vào chat AI.
3. Thay các ô trong ngoặc vuông bằng yêu cầu và dữ liệu thực tế. Ô tùy chọn có thể bỏ; đọc phần `Cách dùng` của từng file.
4. Kiểm tra đầu ra; yêu cầu sửa cụ thể hoặc cung cấp thêm thông tin.

Dùng bằng cách copy/paste vào chat. Khả năng đọc file, tìm web hoặc chạy code tùy môi trường; khi không làm được, AI cần nói rõ. Xem [hướng dẫn chung](chatgpt_plus/huong_dan_chung.md) để có mẫu đầu vào hoàn chỉnh.

## Nguyên tắc sử dụng

- Không gửi mật khẩu, khóa bí mật hoặc dữ liệu cá nhân không cần thiết.
- Tìm kiếm: cần nguồn thực sự đọc được, ngày và giới hạn; không chấp nhận URL bịa.
- Phân tích: phân biệt dữ kiện, giả định, suy luận và phép tính.
- Viết/sáng tạo: giữ dữ kiện đã chốt, ghi rõ nội dung hư cấu.
- Code: code đề xuất không đồng nghĩa đã sửa file hoặc chạy kiểm thử.
- Quyết định: ghi tiêu chí, đánh đổi và dữ liệu thiếu; người dùng quyết định cuối cùng.

## Thêm prompt mới

Mỗi prompt cần mục đích rõ, ô điền dễ hiểu, kết quả mong muốn và ví dụ ngắn khi cần. Giữ hướng dẫn vừa đủ cho tác vụ, tránh thuật ngữ khó hoặc quy trình nhiều bước. Thêm liên kết vào README nhóm; tránh nhiều prompt chỉ khác tên nhưng cùng việc.

## Khu vực Agent nâng cao

[prompt_library](prompt_library/README.md) và tệp nén `prompt_library.zip` là bộ công cụ riêng dành cho Agent nâng cao. Các prompt cơ bản ở danh mục trên dùng độc lập, không cần bộ công cụ này.

## Trạng thái kiểm chứng

Danh mục cơ bản gồm 33 prompt tác vụ, 7 file hướng dẫn/prompt/mẫu trong `chatgpt_plus/`, 12 README nhóm và README gốc. Nội dung đã được đọc lại và kiểm tra cấu trúc/liên kết; chưa thử nghiệm so sánh trên nhiều model. Bạn vẫn cần kiểm tra kết quả trước khi dùng.

[Báo cáo audit trước lần giản lược](docs/PROMPT_AUDIT.md) lưu đánh giá của phiên bản trước, không phải hướng dẫn sử dụng hiện tại.
